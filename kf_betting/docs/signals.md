# Модели сигналов

Все три модели работают **без контекста матча** — только история кэфов.  
Цель: проверить, можно ли зарабатывать исключительно на движении линий.

## Общие ограничения (все модели)

| Параметр | Значение | Смысл |
|---|---|---|
| `warm_up` | 90 сек | первые 90 сек после подключения игнорируются — WebSocket сбрасывает все текущие кэфы сразу |
| `min_ref_age` | 15 сек | опорная точка должна быть старше 15 сек — не считаем «движение» внутри первого flush |
| `max_drop_threshold` | 20–30% | слишком большое движение = гол или игровое событие, не шарп-мани |
| `cooldown` | 300–600 сек | повторный сигнал по тому же исходу не раньше N секунд |

---

## 1. Steam (за движением)

**Гипотеза:** резкое падение кэфа = шарпы зашли с инсайдом → ставим туда же.

```
Δ = (odds_now - odds_ref) / odds_ref
Сигнал если: -25% < Δ ≤ -5%  за последние 60 сек
```

| Параметр | Значение |
|---|---|
| `drop_threshold` | 5% |
| `max_drop_threshold` | 25% |
| `time_window` | 60 сек |
| `min_odds / max_odds` | 1.30 – 4.00 |
| `cooldown` | 300 сек |

**Направление:** `+1` — ставим на упавший кэф (исход куда пошли деньги).  
**Уверенность:** `min(|Δ| / 15%, 1.0)` — растёт с размером движения.

---

## 2. Fade (против движения)

**Гипотеза:** букмекер перестраховался, рынок перегрелся → откат. Ставим на противоположный исход.

```
Сигнал если: -30% < Δ ≤ -8%  за последние 30 сек
```

| Параметр | Значение |
|---|---|
| `drop_threshold` | 8% |
| `max_drop_threshold` | 30% |
| `time_window` | 30 сек |
| `min/max_odds` (противоп.) | 1.50 – 5.00 |
| `cooldown` | 300 сек |

**Направление:** `-1` — ставим на противоположный исход (только для 1X2).  
**Уверенность:** `min(|Δ| / 16%, 1.0) × 0.7` — намеренно ниже чем у Steam.

---

## 3. Momentum (тренд)

**Гипотеза:** если кэф падает N раз подряд, информация поступает постепенно → тренд продолжится.

```
Сигнал если: N=4 последовательных снижения, суммарно -3% .. -20%
```

| Параметр | Значение |
|---|---|
| `steps` | 4 |
| `min_total_drop` | 3% |
| `max_total_drop` | 20% |
| `min_odds / max_odds` | 1.40 – 3.50 |
| `cooldown` | 600 сек |

**Направление:** `+1` — ставим по тренду.  
**Уверенность:** `(|Δ|/10%) × 0.5 + (steps/6) × 0.5`

## Сайзинг ставок (Kelly)

```
p_fair  = 1 / odds                         # нейтральная вероятность
p_model = p_fair × (1 + confidence × 0.20)  # модель добавляет edge до 20%
kelly   = (p_model × (odds-1) - (1-p_model)) / (odds-1)
stake   = bankroll × kelly × 0.25           # ¼ Kelly
stake   = clamp(stake, min=50, max=bankroll×5%)
```

¼ Kelly снижает риск разорения при неверных оценках вероятности.

## Разрешение ставок

| Рынок | Логика |
|---|---|
| **1X2** | home > away → П1; равно → Ничья; home < away → П2 |
| **Тотал** | линия из `specifiers` (`total=X.X`); push если ровно на линии → void |
| **Фора** | `home + hcp` vs `away`; push если равно → void |
| **Обе забьют** | home > 0 AND away > 0 |

Ставки без финального счёта через 6 часов → `void` (возврат).
